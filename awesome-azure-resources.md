# 🌟 Curated Awesome Azure Resources

A hand-picked list of official Microsoft repositories, developer tools, community projects, and learning paths.

---

## 🏛️ Official Microsoft Repositories

- [**Azure Architecture Center**](https://github.com/mspnp/architecture-center): Official reference architectures and code samples.
- [**Azure Quickstart Templates**](https://github.com/Azure/azure-quickstart-templates): Community-contributed ARM and Bicep templates for provisioning any Azure service.
- [**Azure Enterprise-Scale Landing Zones**](https://github.com/Azure/Enterprise-Scale): Reference implementation for enterprise cloud adoption.
- [**Azure Terraform Verified Modules**](https://github.com/Azure/terraform-azurerm-caf-enterprise-scale): Microsoft CAF Terraform module.
- [**Azure CLI Repository**](https://github.com/Azure/azure-cli): Official repository for the `az` command line tool.
- [**Azure PowerShell Repository**](https://github.com/Azure/azure-powershell): Official repository for `Az` cmdlets.
- [**Azure Bicep**](https://github.com/Azure/bicep): Domain-specific language (DSL) for declarative deployment of Azure resources.

## 🛠️ Essential Developer & Admin Tools

| Tool | Description | Link |
| :--- | :--- | :--- |
| **Azure Storage Explorer** | Free GUI app to inspect Blobs, Queues, Tables, and Data Lake files | [Download](https://azure.microsoft.com/en-us/products/storage/storage-explorer/) |

| **TFSec / Trivy** | Security scanner for Terraform and cloud configuration files | [GitHub](https://github.com/aquasecurity/trivy) |
